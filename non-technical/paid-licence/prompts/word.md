# Copilot in Word

## Start a draft

> Draft a one-page briefing note for [who], who needs to decide [what]. Use [/file name] as the source. Put [to confirm] wherever a fact is missing.

> Write a first draft of a [proposal / report / guide] on [topic], using [/file] and [/file]. Use headings and short paragraphs. Keep the main point first.

> Using the attached template's headings, draft each section from these notes: [paste or /file].

## Improve what's there

> Rewrite this section in plain English for [who]. Keep every fact, date and amount exactly as it is.

> Make this shorter by about a third without losing any decisions, dates or actions.

> Is the main point clear in the first two lines? If not, rewrite the opening.

> Turn this paragraph into a table with columns for [A], [B] and [C].

## Ask about a long document

> Summarise this document in five bullets, then list every action, deadline and decision, with the section for each.

> What does this document say about [topic]? Quote the wording.

> What questions would [role] ask after reading this? Which ones doesn't it answer?

> What would a new starter find confusing here?

## Before you use it

- Copilot can add details that aren't in your source. Check every fact, number and name it wrote. The **Laya Second Check** can do this against the source.
- For anything going to members or a regulator, follow your team's approval route. A clean draft isn't an approved one.
- To carry on across several sittings with a clear record, use the **Laya Document Co-author**.
