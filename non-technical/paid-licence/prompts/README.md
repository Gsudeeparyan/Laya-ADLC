# Prompt packs for the paid licence

Each pack has ready-to-use prompts for Copilot inside one app. Copy one, change the [brackets], and read the result before you use it.

| Pack | For |
|---|---|
| [Word](word.md) | Drafting, rewriting, summarising, asking about a long document |
| [Excel](excel.md) | Quick analysis, formulas, charts |
| [PowerPoint](powerpoint.md) | Decks from documents, tidying slides, speaker notes |
| [Outlook](outlook.md) | Long threads, replies, tone |
| [Teams](teams.md) | Meetings and chats |
| [Work chat](work-chat.md) | Questions across your work, plus Researcher and Analyst |

Prompts for the free version are in [everyday prompts](../../prompts/everyday-prompts.md), and they all work on the paid licence too.
