# Projects and operations

**Where AI helps:** turning ideas into plans, mapping processes, tracking risks and writing status updates.

**What stays with you:** the plan's realism, priorities and commitments. AI will produce a neat plan for something impossible.

## Jobs AI can help with

These work on the free version as well as the paid licence. Change the [brackets], and leave real names and member details out.

| Your job | Use | Try saying |
|---|---|---|
| Shape an idea | Laya Idea Refiner | I've an idea for improving [process]. Help me work out whether it's worth doing and write a one-page brief. |
| Plan a project | Laya Project Planner | Plan this project: the goal, the milestones, who's accountable for each, and the risks. Start with the smallest version that works end to end. |
| Report status | Laya Project Planner (upload the plan workbook) | Write this week's status from the plan. Give an honest Red, Amber or Green, with the reason. |
| Keep a risk log | Laya Excel Builder | Make me a RAID log for this project, with an owner and a review date on each entry. |
| Map a process | Laya Process & SOP Builder | Help me map how [process] works now, and show where it waits, is handed over or gets re-keyed. |
| Ask IT for something | Laya Requirements Writer | We need [change]. Help me write what we need so IT or a supplier can build it, with testable requirements. |
| Run a retrospective | Laya Agile Coach | Help me run a 30-minute retro for a team of [number] that just finished [what]. |
| Pitch it | Laya Presentation Builder | Help me build a five-slide pitch for [decision] for [audience]. |

## If you have the paid licence

- **Laya Catch Me Up:** a fast read on what's moved across a project.
- **Laya Meeting Recap:** actions from a project meeting, ready for the tracker.
- **Copilot in Excel:** quick analysis of the plan.

## Check before you use it

- Check dates and dependencies with the people doing the work.
- Make sure every action has one named owner, and that they've agreed to it.
- Don't let a neat status report hide a real problem: red means red.

## Never hand these to AI

- Committing people, money or dates.
- Telling a supplier or another team what's agreed, without you reading it.
- Reporting status you haven't checked.

## Data to watch

Project files can hold member data or staff details by accident. Use the Laya PII Guard on anything that came from a live system.

Use the **Laya Privacy & AI Check**, or ask your manager. If something has already gone wrong, see [When something goes wrong](../staff-guide/when-something-goes-wrong.md).
